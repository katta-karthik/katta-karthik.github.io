## Portfolio

- A dark, responsive layout with sticky navigation and an agent animation that respects reduced-motion preferences.
- Sections for expertise, projects, open-source work, and contact links.
- An About section with a short bio, experience, and engineering toolkit.

The site uses HTML, CSS, system fonts, and a CSS animation showing agents collaborating, with a small JavaScript pause control. Project details expand with native HTML controls.

---

## Deploy to GitHub Pages

The [live portfolio](https://katta-karthik.github.io/) is served from the root of the `main` branch in [katta-karthik/katta-karthik.github.io](https://github.com/katta-karthik/katta-karthik.github.io). With that repository configured as the `user-site` remote, publish a reviewed commit with:

```bash
git push user-site HEAD:main
```

---

## 💻 Local Preview

You can run a local development server using Python:

```bash
python -m http.server 8000
```
Then open your browser at `http://localhost:8000`.
