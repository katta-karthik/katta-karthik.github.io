Research assistant

DeepScope

Give DeepScope a question and it writes a research report. Different assistants look into different parts of the question, then another checks what they might have missed.

Source code ↗
Technical details

LangChain Deep Agents · LangGraph · Filesystem context

  1. Plan

    A lead agent breaks the research objective into questions that can be investigated independently.

  2. Delegate

    Specialized agents research those questions and write findings to disk, keeping bulky evidence out of the lead agent’s context.

  3. Verify

    A fact-verification agent checks the findings and identifies gaps before the final report is written.

  4. Synthesize

    The lead agent draws on the verified findings to write the report.

Technical details

ChromaDB · BM25 · FlashRank · Groq · Streamlit

  1. Ingest

    Parse, clean, and split documents into semantic chunks while keeping track of their source pages.

  2. Retrieve

    Search ChromaDB vectors and BM25 keywords, then combine the two rankings with Reciprocal Rank Fusion.

  3. Rerank

    Use FlashRank to score how well candidate passages answer the question before sending them to the model.

  4. Cite

    Generate an answer from the retrieved context and cite the source pages so readers can check the evidence.

Sales assistant

E-commerce AI Analytics

Ask a question like “What sold best last month?” The assistant checks the sales records and can show the answer in a chart. If the first attempt fails, it can fix the error and try again.

Live demo ↗Source code ↗
Technical details

LangGraph · SQLite · Gemini · Meta Prompt Guard · MCP

  1. Draft

    The agent translates “Show me total revenue” into a query. In this example, it assumes the sales table has a revenue column.

  2. Fail

    SQLite returns no such column: revenue. LangGraph routes that error back to the query planner.

  3. Repair

    The agent rewrites the query using the schema. In this example, it totals the line items using SUM(quantity * unit_price).

  4. Return

    The revised query runs in the read-only database session. The agent can use the returned data to generate a chart.
